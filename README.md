# خطة إغلاق مشروع أبطال القرى

صفحة تفاعلية لمتابعة خطة إغلاق مشروع «أبطال القرى» التابع لجمعية التنمية الأهلية بالحريضة (18 بندًا).

- نماذج إلكترونية لكل بند، مع حسابات تلقائية (النتائج والترتيب، الإيرادات النقدية والدعم العيني، المصروفات، الحساب الختامي).
- توقيع إلكتروني (رسم أو رفع صورة)، وتسلسل اعتماد للبنود المالية.
- إرفاق الفواتير والمستندات (صور أو PDF).
- تصدير PDF عربي (مع المرفقات) و Word.

## الحفظ والمزامنة بين الأجهزة
تُحفظ البيانات في متصفح كل جهاز، ويمكن تفعيل «☁️ المزامنة» لحفظها في مستودع GitHub خاص (مثل `abtal-alqura-data`) باستخدام مفتاح Fine-grained بصلاحية Contents: Read and write على ذلك المستودع فقط. بعد التفعيل يرفع زر «حفظ» التغييرات، وتحمّل الأجهزة الأخرى أحدث نسخة عند فتح الصفحة.
